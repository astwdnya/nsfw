# The Iron Giant 2 - iOS App

Native iOS WebView wrapper for The Iron Giant 2 Flash game, running with WebAssembly Ruffle emulator.

## How to build
The GitHub Actions workflow runs automatically on push or can be triggered via the Actions tab.

## Downloading the IPA
1. Go to the **Actions** tab in this GitHub repository.
2. Click the latest **Build Native iOS IPA** workflow run.
3. Scroll down to **Artifacts** and download **TheIronGiant2-iOS-IPA**.
4. Open with **ESign** or **Sideloadly** on your iPhone and sign!
